# 🏫 계산공업고등학교 식품생명과학과 카페 키오스크 시스템

## 📋 프로젝트 개요

**실제 운영 가능한 고등학교 카페 키오스크 시스템**으로, 기존 HTML 기반 시스템의 한계를 극복하여 실시간 주문 관리와 다중 기기 연동을 지원합니다.

### 🎯 주요 특징
- ✅ **실시간 주문 관리**: 서버리스 데이터베이스 연동
- ✅ **다중 기기 동기화**: 주문 키오스크 ↔ 관리자 시스템 실시간 연동
- ✅ **학생 할인 시스템**: 고객 구분별 자동 할인 적용
- ✅ **직관적인 UI/UX**: 터치 스크린 최적화된 인터페이스
- ✅ **관리자 대시보드**: 실시간 주문 현황 및 매출 통계
- ✅ **완전한 CRUD**: 주문 생성, 조회, 수정, 삭제 지원

---

## 🚀 **핵심 솔루션: 기존 문제점 해결**

### ❌ **기존 시스템의 문제점**
1. **LocalStorage 제한**: 도메인별 분리로 다중 기기 간 데이터 공유 불가
2. **Firebase 연동 불가**: 정적 웹 환경에서 실시간 동기화 제한
3. **데이터 지속성 부재**: 새로고침 시 모든 주문 데이터 손실

### ✅ **새로운 시스템의 해결책**
1. **RESTful API**: 브라우저 기반 실시간 데이터베이스 연동
2. **서버리스 아키텍처**: 별도 서버 구축 없이 완전한 백엔드 기능
3. **실시간 동기화**: 5초마다 자동 데이터 업데이트

## 🎮 **사용법**

### 🛒 **고객 주문 프로세스**

#### **Step 1: 메뉴 선택**
1. 화면 상단 카테고리 버튼 터치
   - 📱 **전체 메뉴**: 모든 상품 보기
   - ☕ **커피**: 아메리카노, 라떼, 카푸치노 등
   - 🥤 **논커피**: 녹차라떼, 초콜릿라떼, 스무디 등
   - 🍰 **디저트**: 케이크, 티라미수, 아이스크림 등
   - 🥖 **베이커리**: 크루아상, 베이글, 머핀 등

#### **Step 2: 장바구니 관리**
1. 원하는 메뉴 카드 터치 → 자동으로 장바구니에 추가
2. 우측 장바구니에서 수량 조절:
   - ➖ **빼기** 버튼: 수량 감소
   - ➕ **더하기** 버튼: 수량 증가
   - 🗑️ **삭제** 버튼: 해당 상품 제거

#### **Step 3: 고객 구분 선택**
- 👨‍🎓 **학생**: 10% 자동 할인 적용
- 👨‍🏫 **교직원**: 정가 결제
- 👥 **방문자**: 정가 결제

#### **Step 4: 주문 완료**
1. **'주문하기'** 버튼 터치
2. **주문번호** 확인 (예: KS1001)
3. **주문 완료 알림** 확인
4. 주문번호로 대기

### 👨‍💼 **관리자 운영 프로세스**

#### **Step 1: 실시간 모니터링**
- **대시보드 통계 확인**:
  - 🟡 접수 대기: 신규 들어온 주문
  - 🔵 준비 중: 현재 제조 중인 주문
  - 🟢 준비 완료: 고객 픽업 대기 중
  - 📊 오늘 총 주문 수
  - 💰 오늘 매출 금액

#### **Step 2: 주문 상태 관리**

**🟡 접수중 → 🔵 준비중**
1. 신규 주문 확인
2. **"준비시작"** 버튼 클릭
3. 상태가 "준비중"으로 변경

**🔵 준비중 → 🟢 준비완료**
1. 상품 제조 완료 후
2. **"준비완료"** 버튼 클릭
3. 고객에게 픽업 안내

**🟢 준비완료 → ⚫ 수령완료**
1. 고객이 상품 수령 후
2. **"수령완료"** 버튼 클릭
3. 주문 처리 완료

#### **Step 3: 예외 상황 처리**

**주문 취소**
- 준비 전 단계에서 **"취소"** 버튼 클릭
- 취소 사유 확인 후 처리

**상태 되돌리기**
- 실수로 상태 변경 시 이전 단계로 복원 가능
- **"준비중으로"**, **"준비완료로"** 버튼 활용

## 🆘 **문제 해결 가이드**

### **일반적인 문제들**

#### **1. 주문이 표시되지 않는 경우**
**원인**: 네트워크 연결 문제
**해결방법**:
1. 인터넷 연결 상태 확인
2. 브라우저 새로고침 (F5 또는 Ctrl+R)
3. 다른 디바이스에서 접속 테스트

#### **2. 메뉴가 로드되지 않는 경우**
**원인**: 데이터베이스 연결 오류
**해결방법**:
1. 페이지 완전 새로고침 (Ctrl+Shift+R)
2. 브라우저 캐시 삭제
3. 개발자 도구에서 네트워크 상태 확인

#### **3. 주문 상태 변경이 안되는 경우**
**원인**: 권한 또는 동기화 문제
**해결방법**:
1. 관리자 페이지 새로고침
2. 다른 브라우저로 접속 시도
3. 잠시 후 다시 시도 (서버 동기화 대기)

### **기술적 디버깅**

#### **개발자 도구 활용법**
1. **F12** 키 또는 **우클릭 → 검사** 선택
2. **Console 탭**: JavaScript 에러 확인
3. **Network 탭**: API 호출 상태 확인
4. **Application 탭**: 로컬 데이터 확인

#### **API 상태 확인**
```javascript
// Console에서 직접 테스트

  .then(response => response.json())
  .then(data => console.log(data));
```
